# 📖 用語集

[[ホーム]] に戻る

このアプリのコード・ドキュメントで使う言葉。試験科目の用語ではなく**開発側の語彙**です。

---

## 学習まわり

**箱(box)**
: 間隔反復の段階。1〜4がLeitnerの箱で、数字が大きいほど次回まで間隔が長い。5は卒業。→ [[学習アルゴリズム]]

**期日(due)**
: 次にその問題/語を出題する日(`YYYY-MM-DD`)。今日以前なら「復習どき」。

**卒業**
: 箱4で正解して復習キームから外れた状態。**削除せず墓標として残す**。

**墓標(tombstone)**
: 卒業を表すエントリ `{box:5, due:"9999-12-31"}`。削除だと同期で復活するための工夫。→ [[同期とマージ規則]]

**ことば帳 / 用語ノート**
: 間違えた問題に出てきた用語を自動で集めたノート。問題単位とは別の間隔反復キューを持つ。

**ドリル(反復学習)**
: 正解するまで繰り返すモード。1問2回で打ち切る。

**計算ドリル**
: 計算問題だけを公式のテーマ別に特訓するモード。1問ごとの解答時間を測る。→ [[学習アルゴリズム#計算ドリル]]

**テーマ(計算テーマ)**
: 計算問題を「解くのに使う公式」で束ねた単位(稼働率・待ち行列など全15)。分野(middle)とは別物。

**公式カード**
: テーマごとの「公式+解き方の型+目標秒数」。計算ドリルで誤答すると必ず表示される。`calc-themes.json` に手書き。

**遅延保持率**
: 7日以上あけて解き直した問題の正解率。詰め込みでは上がらない指標。

**モード**
: 解答の記録種別。`practice` / `drill` / `calc` / `review` / `mock` の5つ。

**学習セッション**
: タブを開いている間ひとまとまりの学習。`sessionStorage` のIDで識別。

**バックフィル**
: 過去の解答履歴から、ことば帳などの導出データをまとめて作ること。冪等。

## データまわり

**ProgressState**
: `ap-study:v1` に保存される学習データ本体。→ [[データモデル]]

**attempts**
: 解答履歴。**追記専用**で、他の集計はすべてここから導出できる。

**LWW(Last-Write-Wins)**
: 衝突したとき「後に書いた方が勝つ」規則。このアプリでは**エントリ単位**で判定する。

**`u`(エントリ更新時刻)**
: 復習・ことば帳の各エントリが持つタイムスタンプ。同期の勝敗に使う。
導出で作ったエントリは `u=0` にして、実際の学習操作に必ず負けるようにしている。

**`settings.meta`**
: 設定のキーごとの更新時刻。**削除も同期で伝える**ために必要。

**修復(repair)**
: 解答履歴をリプレイして、壊れた復習キューを正しい状態に直す処理。起動時と同期後に実行。

## 問題データまわり

**examId**
: 試験回のID。`<西暦>r<令和年><a|h>`(a=秋期、h=春期)。令和2年度のみ `2020r02o`(10月)。

**大分類 / 中分類**
: `major`(T=テクノロジ / M=マネジメント / S=ストラテジ)と、その下の22分類 `middle`。

**point(初学者ポイント)**
: 問題ごとの覚え方メモ。「用語=説明」形式で書くと**用語カードの生成源**になる。

**choicesInFigure**
: 選択肢そのものが図の中にある問題。`choices` が空でも「(図のア)」等が自動合成される。

**逐語切り出し**
: 用語カードの定義を過去問の本文からそのまま抜き出す方式。誤った定義が混入しない。

**overrides**
: 生成データの手動修正ファイル(`term-overrides.json` 等)。生成物を直接編集しないための仕組み。

## 配信・AIまわり

**ブリッジ(Codexブリッジ)**
: ChatGPTサブスクのCodex枠をアプリから使うためのローカルサーバー(`127.0.0.1:8399`)。

**同一オリジン**
: アプリとブリッジを同じURL(`http://127.0.0.1:8399/`)から開く運用。
ブラウザのCORS・混在コンテンツ制限を回避できる**推奨構成**。

**同期コード**
: 端末間で同じ学習データを共有するための合言葉。認証はなく、個人利用に割り切った方式。

**マーク(AIマーキング)**
: AIが解説時に問題文へ引く蛍光マーカー/下線。返答末尾のJSONで指定される。
