# ✨ AI連携

[[ホーム]] に戻る

アプリにサーバーはありません。AI機能は**利用者自身の接続先**を使います(BYO)。
未設定でもアプリの学習機能はすべて動きます。

---

## 接続先(4種類)

| プロバイダ | 方式 | キー |
|---|---|---|
| Codex(ChatGPTサブスク) | Macで動くローカルブリッジ経由 | 不要 |
| OpenAI / Anthropic / xAI | 各社の公式APIへ直接 | 自分のAPIキー |

実装: `src/lib/aiChat.ts`(ストリーミング共通入口)、`aiConfig.ts`(設定)。
キーは `ap-study:ai` に隔離保存し、**同期・エクスポートには含めません**。

---

## AIチャット `src/components/AiChat.tsx`

- 右上の✨から開くサイドパネル(PCは横並び、スマホは下シート)。**問題を見ながら質問できます**
- いま表示中の問題(問題文・選択肢・正誤・解説)を自動で共有(`aiContext.ts`)
- 入力欄で **↑/↓ キー**が過去の質問を呼び出します(ターミナル風、最大50件)
- 返答はプレーンテキストとして描画(HTMLは実行しません)

### 重要箇所のマーキング
チェックボックスをONにすると、AIが解説時に問題文・選択肢の根拠部分へ
**蛍光マーカー/下線**を引きます(`aiHighlight.ts`)。

仕組み: 返答の末尾に ```` ```marks ```` で囲んだJSONを書かせ、引用文字列を本文中から
探して範囲に変換します。壊れていたら**黙って何もしない**(縮退)方針です。

## 午後問題のAI採点 `src/lib/aiGrade.ts`

記述解答を模範解答と突き合わせ、**○△×の推定+講評**を返します。
推定はそのまま自己採点欄に入り、**利用者が後から変更できます**。
講評は `pm.<問題>.<設問>.ai` に保存され、同期でも独立に保持されます(→ [[同期とマージ規則]])。

## Codexブリッジ `scripts/codex-bridge.mjs`

ChatGPTサブスクのCodex枠を使うためのローカルサーバー(既定 `127.0.0.1:8399`)。

```bash
npm run codex-bridge
```

- 認証は公式の Codex App Server が管理し、**トークンはこのプロセスを通りません**
- `npm run build` 済みなら**アプリ本体も配信**します
- チャット1回ごとに読み取り専用サンドボックスの隔離スレッドで実行

> [!tip] 確実に使う方法
> ブラウザで **http://127.0.0.1:8399/** を開いてください。
> アプリとブリッジが同一オリジンになり、CORS・Private Network Access・
> 混在コンテンツ(Safari含む)の制限を**一切受けません**。

> [!warning] 公開サイトから使うときの制約
> ブリッジのCORS許可リストは GitHub Pages と開発サーバーのみです。
> **CloudFront配信のURLからは接続できません**(ブラウザが応答を破棄し、
> アプリには「ブリッジに接続できません」と出ます)。
> 回避策: 上記の同一オリジン、または `--allow-origin <URL>` で許可を追加。
> ただしSafariはhttpsページからhttp://127.0.0.1への通信自体を遮断します。

### 既知の弱点(未修正)
- `codex` の起動に2回失敗すると、**ブリッジを再起動するまで再試行しません**
- 起動失敗の理由(stderr)を保持しているのに**どこにも出力していない**ため、原因が追えません
- 初期化がタイムアウトすると以降ずっと同じ失敗を返し、応答しないプロセスも残ります

→ [[既知の課題]] / 切り分け手順は [[トラブルシューティング#Codexブリッジ]]

## 設計方針

> [!note] AIは「あると嬉しい」に留める
> 学習の中核(出題・採点・復習・用語辞書)は**AIなしで完結**させています。
> 用語カードの定義を過去問からの逐語切り出しにしているのも同じ理由で、
> AI生成の誤った定義で覚えてしまう事故を構造的に防ぐためです(→ [[決定記録]])。
