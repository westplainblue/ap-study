## 計算特化モード(Phase 3 のみ残)

**Phase 1・2 は実装済み**(🧮 計算ドリルとして稼働中)。全体像は [[機能マップ#計算ドリル]]、
設計判断は [[決定記録#計算ドリルのテーマ分類を問題データと分離した]] を参照。

残りの **Phase 3(定着)**:
- 分析画面に計算モードの推移(**テーマ別の正答率と平均解答時間**)。
  データは `Attempt.ms` に記録済みなので集計と表示だけ
- **苦手テーマからの再出題**導線(結果画面や分析からワンタップで)
- 計算ドリル関連の**実績**の追加
