## 計算特化モード

**方針は決定済み・未着手**。計算問題は午前880問中**157問(17.8%)**、1回あたり10〜19問。
テーマで括ると財務・原価26、基数変換13、稼働率12、伝送12、性能計算11…と
**限られた公式の使い回し**であることがデータで確認できています。

失点要因は知識不足ではなく「公式が引き出せない」「時間内に処理できない」の2つ。そこで:

1. **テーマ(公式)別に束ねる** — 同じ公式を連続で解く「集中」と、混ぜる「ごちゃまぜ」を選べる
2. **1問ごとの時間を測る** — テーマごとの目標時間に対して速いか遅いかを可視化
3. **公式カードを添える** — 10〜15テーマ分を手書きし、誤答時に提示

### 実装の骨子
- 問題データ(`*.am.json`)は**触らない**。テーマ分類は別ファイル
  (`calc-themes.json` / `calc-index.json` + 生成スクリプト + overrides)。
  用語辞書と同じ「機械生成 + キュレーション + テストで不変条件」の型
- 記録は `mode: "calc"` を追加(分析のモード別正答率に自動で並ぶ)
- 解答時間は `Attempt` の**任意フィールド**として追加(後方互換)
- 画面は `/calc` + `/calc/run`。出題本体は既存Playerを拡張せず新規コンポーネント
- 入口はホームのメニュー(タブバーは増やさない)

### 段階
- **Phase 1**: 判定漏れ(`2021r03a-am-17`)の修正、テーマ分類の生成、公式カードの執筆
- **Phase 2**: セットアップ画面、出題+タイマー+公式カード、結果画面、ホーム導線
- **Phase 3**: 分析にテーマ別の正答率と平均解答時間、苦手テーマからの再出題
