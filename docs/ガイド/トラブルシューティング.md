## 追加した過去問が出てこない

1. `src/data/index.ts` に **importと `EXAMS` への追加**をしたか(手動作業・忘れやすい)
2. `npm run build:terms` を実行したか(用語辞書に新しい回が入らない)
3. `npm test` が通るか(問題数・図表の参照切れをテストが検出します)
4. それでも出ない → 上の「反映されない」へ

## Codexブリッジ

### 「ブリッジに接続できません」と出る
ブリッジは動いているのに出る場合、**アプリを開いているURLが許可リストにない**のが典型です。

```bash
# 確実な回避策: ブリッジ自身がアプリを配信する(同一オリジン)
npm run build && npm run codex-bridge
# → ブラウザで http://127.0.0.1:8399/ を開く
```

公開URLのまま使いたい場合は `npm run codex-bridge -- --allow-origin <アプリのURL>`。
**Safariは不可**(httpsページからhttp://127.0.0.1への通信を遮断するため)。

### 「Codex App Serverが終了しました」「再起動に繰り返し失敗しました」
CLI側を直接叩いて切り分けます。

```bash
which codex && codex --version
echo '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"clientInfo":{"name":"ap_study","title":"AP Study","version":"0.1.0"},"capabilities":null}}' | codex app-server
lsof -i :8399
```

JSONが返ればCLIは正常。ブリッジ側の既知の弱点(2回失敗で諦める・原因を出力しない)に
当たっている可能性が高いので、**ブリッジを再起動**してください → [[既知の課題]]

## 画面が真っ白になる

`ap-study:mock`(模試の中断状態)が壊れていると、模試の画面でアプリ全体が落ちます
(このキーだけ読み込み時のガードがありません)。

```js
// DevToolsのコンソールで
localStorage.removeItem("ap-study:mock");
```

他のキーは壊れていても空状態で復帰します。→ [[既知の課題]]

---

## 復習の件数がおかしい / 覚えた問題が何度も出る

過去の同期の不具合で「卒業したのに復活した」エントリが残っている可能性があります。
**最新版を開けば起動時に自動修復**されます(解答履歴からリプレイして墓標化)。
仕組みは [[同期とマージ規則#汚染データの自動修復]]。

---

## 設定が元に戻ってしまう(シャッフルON・試験日)

同じく古い版の同期の不具合です。最新版では削除も同期で伝わるようになっています。
複数端末を使っている場合は、**全端末を最新版にしてから**設定し直してください。

---

## 進捗が消えた

1. 設定画面の**エクスポート**でバックアップが取れます(定期的にどうぞ)
2. 同期コードを設定していれば、他端末から復元できる可能性があります
3. localStorage が壊れると空状態で起動し、次の解答で上書きされます(既知の弱点)。
   **心当たりがあるときは、まず何も解答せずにDevToolsで `ap-study:v1` を確認**してください

---

## テストだけ落ちる・E2Eが不安定

`tests/` は安定していますが、使い捨てのE2Eスクリプトはタイミングに敏感です。
1回の失敗で判断せず、再実行して再現するか確かめてください。
既知のハマりどころ → [[テストと検証の作法#落とし穴(実際にハマったもの)]]
